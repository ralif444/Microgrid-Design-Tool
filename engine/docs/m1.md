# M1 — equation and unit audit (Doc 9 D-49 K32)

Code: `src/mgengine/m1.py`, `src/mgengine/network.py`. Equation numbers refer to the manuscript
`docs/ref/Seminar.pdf` (4.2.3). Engine units are SI per phase (D-49 K28).

## Symbols

| Symbol | Meaning | Unit | Code field |
|---|---|---|---|
| V_i | bus phase RMS voltage magnitude | V | `v_v`, state `x[:n]` |
| θ_i | bus voltage angle, θ_1 = 0 (reference, K29) | rad | `theta_rad` |
| ω | system angular frequency | rad/s | `omega_rad_s` |
| P, Q | three-phase totals | W, VAR | `p_w`, `q_var` |
| R, X | per-phase series line totals | Ω | `r_ohm`, `x_ohm` |
| G, B | bus admittance Y = G + jB | S | `admittance()` |
| m_p | frequency droop | rad/(s·W) | `m_p_rad_s_per_w` |
| n_q | voltage droop | V/VAR | `n_q_v_per_var` |
| ω*, V*, P*, Q* | droop setpoints | rad/s, V, W, VAR | `omega_set_rad_s`, `v_set_v`, `p_set_w`, `q_set_var` |

## Equations

| Eq. | Form in code | Unit check |
|---|---|---|
| (4.5) | P_i = P*_i + (ω* − ω)/m_p, Q_i = Q*_i + (V* − V)/n_q; summed per bus as `a_p − b_p ω`, `a_q − b_q V` | (rad/s)/(rad/(s·W)) = W; V/(V/VAR) = VAR |
| (4.6) | x = [V_1..V_n, θ_2..θ_n, ω], size 2n | V, rad, rad/s |
| (4.7) | S = 3 V̄ conj(Y V̄), V̄ = V e^{jθ}; P_net = Re S, Q_net = Im S | 3 · V · S · V = W (VAR) three-phase |
| (4.8) | F = [P_spec − P_net; Q_spec − Q_net], P_spec = droop injection − load; J Δx = −F | W, VAR rows |
| (4.9) | initial ω0 = (Σ ω*/m + Σ P* − P_L)/Σ(1/m), P̂_loss = 0 (K30) | (rad/s·W·s/rad + W)/(W·s/rad) = rad/s |

Jacobian (analytic, polar derivatives of S times 3, no division by |V| because V is a signed
state): ∂F_P/∂V = −Re ∂S/∂V, ∂F_P/∂θ = −Re ∂S/∂θ, ∂F_P/∂ω = −Σ 1/m_p (W·s/rad);
∂F_Q/∂V = −Im ∂S/∂V − Σ 1/n_q (VAR/V), ∂F_Q/∂θ = −Im ∂S/∂θ, ∂F_Q/∂ω = 0. Checked against
central finite differences in `tests/test_m1.py`.

## Status rules (4.2.3)

| Condition | Status / code |
|---|---|
| max\|F\| < tolerance (1e-3, W and VAR) and all V > 0 | FEASIBLE / OK |
| converged with some V ≤ 0 | PHYSICALLY_INADMISSIBLE / OPERATING_POINT_NOT_PHYSICAL |
| cond(J) > 1e12 or not finite | SOLVER_FAILED / ILL_CONDITIONED_JACOBIAN |
| `max_iterations` updates (default 50) without convergence | SOLVER_FAILED / MAX_ITERATIONS_REACHED |
| non-finite state or mismatch | SOLVER_FAILED / NON_FINITE |

M1 never returns INFEASIBLE; limits are M2's job.

## Detailed results (`src/mgengine/results.py`, Doc 9 D-50)

| Quantity | Form in code | Unit check |
|---|---|---|
| line current | I = (V̄_i − V̄_k)/(R + jX), reported \|I\| (phase RMS) | V/Ω = A |
| line flow | S_from = 3V̄_i conj(I), S_to = 3V̄_k conj(−I); positive leaves the bus at that end | 3 · V · A = W (VAR) |
| line losses | P_from + P_to = 3\|I\|²R | 3 · A² · Ω = W |
| inverter output | P = P* + (ω* − ω)/m_p, Q = Q* + (V* − V_bus)/n_q (4.5); S = √(P² + Q²) | W, VAR, VA |
| loading ratio | S / `rated_va` (three-phase) | VA/VA = 1 |
| ε_X | \|ω_s − ω_nom\|/ω_nom (4.1), ω_nom = 2π·`nominal_frequency_hz` (K36) | (rad/s)/(rad/s) = 1 |
| totals | Σ P_L, Σ Q_L, Σ line losses | W, VAR, W |

Sanity checks in `tests/test_results.py` (4.5.2): Σ P_inv = P_L + losses, Σ Q_inv = Q_L + Σ 3\|I\|²X,
losses ≥ 0, S² = P² + Q².

## Conversion points (app → engine, done in the Real Engine adapter, WP 1.4.1)

| App field (Doc 3) | Engine | Conversion |
|---|---|---|
| `voltage_setpoint_kv`, `nominal_voltage_kv` (line-to-line) | V phase | × 1000 / √3 |
| `frequency_setpoint_hz` | ω* | × 2π |
| `frequency_droop_hz_per_kw` | m_p | × 2π / 1000 |
| `p_kw`, `q_kvar`, setpoints | W, VAR | × 1000 |
| `rated_kva` | `rated_va` | × 1000 |
| `nominal_frequency_hz` | ω_nom for ε_X | × 2π |
| `r_ohm`, `x_ohm` | Ω | none |
| `voltage_droop_kv_per_kvar` | n_q | open: whether the kV is line-to-line or phase is not fixed in Doc 3; decided with the user before WP 1.4.1 |

Results go back the other way (ω / 2π → Hz, V · √3 / 1000 → kV line-to-line, W / 1000 → kW).
