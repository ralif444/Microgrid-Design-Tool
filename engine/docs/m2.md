# PS and M2 — equation and unit audit (Doc 9 D-51)

Code: `src/mgengine/ps.py`, `src/mgengine/m2.py`. Equation numbers refer to the manuscript
`docs/ref/Seminar.pdf` (4.2.2, 4.2.4, 4.2.5). Engine units: VA, W, VAR, Wh, phase V, rad/s, A.
Gambar C.2a–b carry older equation numbers ((4.7), (4.8), (4.13)); the text numbers are used here.

## M2 checks (4.10), tolerance (4.11), normalised margin (4.18)

| Kind | Value | Limit (SI, K40) | s_c in (4.18) |
|---|---|---|---|
| BUS_VOLTAGE_MIN / MAX | V_b (phase V) | v_min_v, v_max_v | v_max − v_min if both set, else \|l\| |
| FREQUENCY_MIN / MAX (SYSTEM) | ω (rad/s) | omega_min/max_rad_s | band width, else \|l\| |
| INVERTER_LOADING | S_i / S_r,i | μ_max | \|μ_max\| |
| LINE_CURRENT | \|I_ℓ\| (A) | per-line limit (K43) | \|l\| |
| POWER_BALANCE (SYSTEM) | \|ΣP_inv − P_L − P_loss\| (W, K42) | ε_bal | \|ε_bal\| |

Upper bound: margin = u − x, violated when x > u + (1e-12 + 1e-9\|u\|). Lower bound: margin
= x − l, violated when x < l − (1e-12 + 1e-9\|l\|). Normalised margin = margin / s_c; the list is
sorted by it, ties by kind then element id. A missing limit goes to `not_evaluated`.
(4.10) states S_i/1000 ≤ μ S_r,i with S_r in kVA; in VA this is S_i/S_r,i ≤ μ.

## Loadability (4.14)–(4.16), Gambar C.2b

- (4.14) every load scaled by λ at constant power factor.
- Point status: M1 not FEASIBLE → failure; otherwise the (4.10) checks give FEASIBLE or
  INFEASIBLE.
- Grid λ = 1 + k·0.05, warm start from the last admissible point. At the first non-FEASIBLE
  grid point λ_c is bisected (bracket ≤ 0.005); at the first failure λ_s is bisected the same way
  and the trace stops. λ_s passes INFEASIBLE points. No interpolation.
- The evaluated-point count (grid and bisection, including λ = 1) stops at `max_points`; then
  λ_s (and λ_c if still open) is the last grid point.
- λ_c = None when λ = 1 is INFEASIBLE. `resolution` = 0.005 (K44).
- (4.16) λ_ub = Σ μ S_r,i / \|Σ(P⁰ + jQ⁰)\| (VA/VA), only with μ set; λ_c > λ_ub raises
  `ImplementationError` (K45).
