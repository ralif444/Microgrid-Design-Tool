# M3a–M3d — equation and unit audit (Doc 9 D-52)

Code: `src/mgengine/m3.py`. Equation numbers refer to the manuscript `docs/ref/Seminar.pdf`
(4.2.5, Gambar C.3a–C.3b). Units: engine SI (rad/s, phase V, ratio, A, W).

## Point evaluation (Gambar C.3a)

M1 from the flat start (K51), then the M2 checks (4.10)–(4.11) of `m2.check`. Point status:
FEASIBLE, INFEASIBLE (code CONSTRAINT_VIOLATED), SOLVER_FAILED or PHYSICALLY_INADMISSIBLE (M1 code).
A failed point has no metrics. Limiting constraint (4.18), K57: on the list sorted by μ̄, the
first violation, else the first check other than POWER_BALANCE.

| Key metric | Source | Unit |
|---|---|---|
| SYSTEM_FREQUENCY | ω | rad/s |
| MIN_BUS_VOLTAGE / MAX_BUS_VOLTAGE | min / max V_b | V (phase) |
| MAX_INVERTER_LOADING | max S_i/S_r,i | ratio |
| MAX_LINE_CURRENT | max \|I_ℓ\| (0 without lines) | A |
| TOTAL_LOSSES | Σ line losses | W |
| ε_X | (4.1) | ratio |
| λ_c (optional) | `m2.trace` with `max_points` (K56) | — |

## M3a (4.17)

| Scheme | Form | When |
|---|---|---|
| CENTRAL | (y(p0 + h) − y(p0 − h)) / 2h | both sides admissible |
| FORWARD | (y(p0 + h) − y0) / h | p0 − h failed |
| BACKWARD | (y0 − y(p0 − h)) / h | p0 + h failed |

Unit of dy/dp: metric unit per parameter unit (adapter converts with both scale factors).
S_norm = (dy/dp)·p0/y0 is unit-free; None when y0 = 0 or p0 = 0 (K53). Not reported, with a
reason: base point not admissible, h = 0 (K58), both sides failed. `status_change`: the two
sides' statuses differ (K52). Ranking per metric by \|S_norm\| descending, ties in request order (K54).

## M3b, M3d

M3b: one point per given grid value (the adapter builds p_k = p_start + kΔp);
`first_infeasible_value` is the first value whose status is not FEASIBLE.
M3d: one point per (x, y); `feasible_fraction` = FEASIBLE points / all points.

## M3c

Deltas to the reference scenario (default: the first) for each metric, only when both points
are admissible: delta = y − y_ref (metric unit), relative = delta / y_ref, None when y_ref = 0
(K55). No ranking.
