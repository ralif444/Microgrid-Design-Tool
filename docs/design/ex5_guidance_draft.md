# EX-5 guidance text: draft for approval

Draft of 2026-11-05 (PRD §7, Doc 7 §2.3, FR-102). English. No result numbers. Each text names the source it paraphrases. After approval the texts go to `screens.<id>.guidance` in `frontend/public/examples/guided-d2.example.json` as `{text, source}`.

Banner line on every example screen: "Example mode: this screen is pre-filled from the guided example. Press Run." Screens with no Run button (S-03, S-05, S-06, S-16) get "Example mode: this screen shows the guided example." On the Fake Engine the banner adds: "Results on the Fake Engine are placeholders. Start with `MGAPP_ENGINE=REAL` to see engine results." (Doc 7 §2.3, verbatim.)

| Screen | Text ("What this step shows") | Source |
|---|---|---|
| S-03 Loads | The guided example is the reference design D2: one constant-PQ load at bus B2, fed through two lines by two grid-forming droop inverters, INV1 at B1 and INV2 at B3. The two inverters have different ratings and different droop gains, so the example shows how droop shares one load. D2 is one of the reference designs of the PSIM validation basis. | Doc 13 §4; manuscript 4.2.1c |
| S-04 Sizing advice | Sizing advice (PS, saran kapasitas awal) estimates the inverter capacity from the load data alone, before a network exists, so it ignores line losses and voltage drop. The example fills the inverter margin and the number of units; press Run to see the advice. Do not Accept it here: accepting replaces INV1 and INV2 with equal units, and the rest of the example would no longer match D2. Press Skip and go on to the network. | manuscript 4.2.2; FR-09 |
| S-05 Network | The network is radial: INV1 at B1, a line to the load bus B2, and a second line to INV2 at B3. The server derives each line's resistance and reactance from its conductor data and length. Nothing needs to change here for the example. | Doc 13 §4; Doc 3 §3.3 |
| S-06 Constraints | Limits are study settings chosen for a design, not values from a standard. The example uses the reference-design study settings for voltage, frequency and inverter loading. The line-current limit and the balance tolerance are left empty on purpose: an empty limit is "not evaluated", listed separately and never counted as satisfied. | manuscript 4.2.4; Doc 3 §3.7 |
| S-07 Power flow (M1) | Power flow (M1) solves the droop equations with frequency as a state and no slack bus. Look at the common frequency, at how the droop gains share the active power between INV1 and INV2, and at the power-sharing advice, which compares that sharing with rating-proportional sharing and is not a constraint. The validity indicators tell whether the model assumptions hold for this design. | manuscript 4.2.3, 4.2.7; Doc 12 P9 |
| S-08 Constraint check (M2) | The constraint check (M2) compares the M1 operating point with the limits and gives a verdict, the margin of each check and the limiting constraint. Checks with an empty limit appear in the not-evaluated list. The loadability margins λ_c and λ_s tell how far the load can be scaled while a solution exists; they are not a stability limit. | manuscript 4.2.4; Eq. 4.15, 4.18 |
| S-09 Sensitivity (M3a) | Sensitivity (M3a) changes each selected parameter by a small relative step and shows how each output metric responds. The example selects the droop gains and ratings of both inverters and all output metrics. Enter a relative step: the example does not set one, because the method has no default step. | manuscript 4.2.5; Eq. 4.17 |
| S-10 Sweep (M3b) | A sweep (M3b) repeats the power flow along one axis and shows how the metrics change along it. The example scales the load over a range that covers D2, D2S and D2H, and records the minimum damping ratio at each point. Enter the number of points: the example does not set it. | manuscript 4.2.5; Doc 13 §4 |
| S-11 Scenarios (M3c) | Scenario comparison (M3c) runs every scenario and compares each one with the reference scenario. The example holds D2 base as the reference and the stressed designs D2S and D2H as load overrides. "Generate N−1 scenarios" adds one scenario per inverter with that inverter removed. | manuscript 4.2.5; Doc 13 §4; FR-80 |
| S-12 Envelope (M3d) | The envelope (M3d) sweeps two axes at once and maps where the design stays feasible. The example sets the X axis to the load scale over the same range as the sweep. Choose the Y axis and the number of points on both axes: the example does not set them. | manuscript 4.2.5 |
| S-13 Small-signal (M4a) | Small-signal stability (M4a) linearises the reduced-order model at the M1 operating point. Look at the eigenvalues, the damping of the dominant mode and the participation factors, which show the states that take part in that mode. The inner-loop time constant τ_in is left empty, so the indicator r_in is not evaluated, and without a damping threshold there is no pass or fail on damping. | manuscript 4.2.6, 4.2.7 |
| S-14 Transient (M4b) | Transient stability (M4b) simulates one disturbance in time on the reduced-order model. The three example disturbances are cases of the PSIM validation basis: a load step at L1, the trip of INV2, and a step in the active-power reference of INV1. RoCoF is reported as a description, not a pass or fail. The settling criteria are not set in the example, so the response gets no transient class until you enter them. | manuscript 4.2.6; Doc 13 §5 |
| S-16 Report | The report lists every run of this Project with its Status, the engine that produced it and its snapshot and result hashes, so each result can be traced and re-run. The results are not yet validated against PSIM. | Doc 7 S-16; Doc 13 §1 |

Report line (S-16 body, also in print), only while example mode is on: "Produced in example mode from the guided example D2."

Digit rule for the FR-102 test (proposed): the text may contain identifiers that carry digits (D2, D2S, INV1, B2, M1, λ_c, N−1), but no standalone number such as `0.2`, `50` or `4`. The source column may contain section and equation numbers.
